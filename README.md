# clarity

Простой тг бот для мониторинга сервера. Создан для обучения, но возможно далее буду добавлять новые функции

Сейчас умеет:
* `/start` — просто отвечает приветствием.
* `/uptime` — показывает, сколько сервер не падал.
* `/freeram` — показывает сколько оперативки занято и сколько всего (в МБ).

Быстрый старт:
* `docker build -t clarity .`
* `docker run --rm --env-file .env clarity`
* не забудьте добавить ваш токен в .env перед запуском!
