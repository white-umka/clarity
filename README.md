# clarity

Простой тг бот для мониторинга моего сервера. Пишу на Go, чтобы прокачать скиллы и заодно иметь удобный инструмент под рукой.

Сейчас умеет:
* `/start` — просто отвечает приветствием.
* `/uptime` — показывает, сколько сервер не падал.
* `/freeram` — показывает сколько оперативки занято и сколько всего (в МБ).

Быстрый старт:
* `git clone https://github.com/white-umka/clarity`
* `cd clarity`
* `chmod +x start.sh`
* `./start.sh`
* не забудьте добавить ваше токен в .env перед запуском!
